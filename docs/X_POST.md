# X post

Every airdrop flags real users as sybils, keeps the rules secret, and answers appeals with a Google Form.

FairDrop keeps the rules secret too, but seals them on-chain before the snapshot. The flagged list is published on chain, so any flagged wallet can build its own proof.

GenLayer validators read the wallet's history blind, bound to the snapshot. The model never sees the rules; code applies the sealed ones, and every validator must reach the same outcome.

On chain: 19 appeals, 2 bad reveals refused, missed reveals auto-won, 2 winners paid pro-rata, griefing recorded nothing, books at 0.
